# 版本约束的原因（改动前请先读）：
#  - yolov5/utils/general.py 依赖 pkg_resources，setuptools>=81 已移除该模块，故锁 <81；
#  - yolov5/models/common.py 与 general.py 在找不到 ultralytics 时会自动执行
#    `pip install -U ultralytics`（运行时联网装包，容易卡住或破坏环境），
#    因此这里预装固定版本；
#  - numpy 2.x 与本项目可用的老版 torch / pandas 不兼容，故限定 <2；
#  - GPU 用户请先按 https://pytorch.org/get-started/locally/ 安装对应 CUDA 版 torch /
#    torchvision，再执行本文件（pip 会保留已满足约束的版本）。
